# Contributing to PainLabPlatform

Contributions to the platform, documentation, and reusable device interfaces
are welcome.

## Discuss and report

Use the repository's issue tracker for questions and proposals. For a problem,
include the relevant environment, steps to reproduce it, and expected versus
observed behavior. Keep reports and attachments free of participant data.

## Make a change

Follow the [development guide](docs/development.md). Keep changes focused,
describe their purpose in the pull request, and report the checks you ran.
Update linked documentation when behavior or an interface changes.

Keep documentation brief and use **PainLabPlatform** consistently. Describe
local experiment interfaces without depending on study-specific files in
`instance/`.

For an interface change, describe its effect on existing tasks or clients.
Changes affecting communication or recording should include appropriate
validation; documentation-only edits should check links and instructions.
