# Using the control panel

Start with an assembled set of device connections and task files; see
[Getting started](getting-started.md) for setup.

1. **Connect devices.** Start clients separately, or launch configured local
   programs from **Device Manage**.
2. **Inspect signals.** Use **Device Detail** to view reports and available
   controls. The device descriptor determines what appears.
3. **Activate a task.** In **Script**, select a task, review it, and choose
   **Activate**. Its logic handles incoming device events.
4. **Monitor and intervene.** Use task readouts and adjustable parameters.
   **Actions** runs declared operator operations; **Device Stats** shows
   connection and traffic information.
5. **Export a session.** Choose **Save File** to export recorded data. See
   [Recording](recording.md) for destinations and export behavior.

Refresh the script or action list after adding local files. Available devices,
controls, and actions depend on the experiment configuration.

To change that configuration, see [Task scripting](task-scripting.md) and
[Device integration](device-integration.md).
